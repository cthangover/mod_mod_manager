# Mod Manager — 모드, 게임, 그리고 모드 문서

Mod Manager는 메인 메뉴의 **모드와 컬렉션** 화면입니다. 어떤 모드가 설치되어 있는지, 각 모드가 무엇을 하는지 살펴보고, 온라인 카탈로그에서 모드를 설치·업데이트하고, 모드를 끄고, 만들어진 게임의 속을 들여다보며 어떤 모드로 이루어져 있는지 확인할 수 있습니다.

메뉴와 함께 항상 로드되는 셸의 일부이므로 게임을 시작하기 전에도 동작합니다.

## 열기

메인 메뉴에서 **모드와 컬렉션**을 고르세요. 화면에는 탭이 둘 있습니다:

- **모드** — 게임이 아는 모든 모드: 설치된 것과 카탈로그가 내놓은 것.
- **컬렉션** — 만들어진 게임들과 각 게임을 이룬 모드 구성.

**← 메뉴**는 메인 메뉴로 돌아갑니다. 오른쪽 위의 **?** 버튼이나 **F1**은 상황별 힌트를 켭니다. 컨트롤에 포인터를 올리면 하는 일이 보이고, 클릭하면 힌트가 고정되며, **Esc**로 나옵니다.

## 모드 둘러보기

![모드 탭: 왼쪽 필터, 표지가 붙은 모드 카드 격자, 힌트가 열린 검색 상자, 정렬과 Refresh catalog 버튼.](assets/mods-list.jpg)

각 카드에는 모드의 표지, 제목, 제작자, 나온 카탈로그, 몇 개의 게임이 쓰는지(**컬렉션 4개에 포함**), 상태와 버전, 그리고 켜기/끄기 스위치가 나옵니다.

- **모드 검색...** — 제목, 제작자 또는 식별자로 걸러 봅니다.
- **이름순 / 작성자순 / 상태순** — 목록을 정렬합니다.
- **필터**는 왼쪽에서 목록을 **상태**(설치 안 됨, 설치됨, 업데이트 있음, 이전 버전 있음, 로컬에서 수정됨, 비활성화됨)와 **분류**(스토리, 게임플레이, 비주얼, 오디오, 라이브러리, 엔진, 도구 등)로 좁힙니다. **초기화**는 필터와 검색을 지웁니다.
- **카탈로그 새로 고침**은 공개된 모드의 현재 목록을 내려받습니다.

*로컬에서 수정됨*은 설치된 파일이 카탈로그의 같은 버전 사본과 다르다는 뜻입니다. 예컨대 직접 고치고 있는 모드이지요.

## 모드 읽어 보기

카드를 클릭하면 페이지가 열립니다: 표지, 버전 선택, 작업들, 모드 manifest의 짧은 설명, 그리고 모드가 갖추고 있다면 **문서** — 이 문서 같은 완전한 안내서입니다.

![모드 페이지: Audio Engine의 표지와 버전, Reinstall과 Disable 버튼, "in 4 collections", 설명, 그리고 언어 선택기가 있는 Documentation 섹션.](assets/mod-page.jpg)

문서는 **설치된** 버전의 안내서입니다. 버전 선택기에서 다른 버전을 고르면, 아래 안내서가 여전히 설치된 버전의 것이라는 알림이 떠옵니다.

**문서 언어.** 문서 제목 오른쪽 선택기는 **자동 · 인터페이스 언어**로 시작합니다. 안내서는 게임 인터페이스 언어를 따릅니다. 그 언어의 안내서가 모드에 없으면 관리자는 모드의 기본 안내서, 그다음 영어, 그다음 처음 발견되는 문서를 보여 줍니다. 안내서 위의 한 줄이 실제 표시 언어(예: `EN`)를 알려 줍니다. 선택기에서 직접 언어를 고를 수도 있습니다. 안내서가 하나도 없는 모드는 manifest 설명을 계속 보여 줍니다.

모드 제작자를 위해: 안내서는 `docs/en.md`에(번역은 `docs/<언어>.md` 또는 `docs/default.md`), 이미지는 곁에 두세요. 예컨대 `docs/assets/screen.png`로 두고 `assets/screen.png`로 참조합니다. 뷰어는 제목, 문단, 목록, 인용, 코드 블록, 링크, PNG/JPEG/WebP 이미지를 이해합니다. HTML, 표, 애니메이션은 실행하지 않습니다.

## 설치, 업데이트, 끄기, 삭제

모드 페이지의 버튼과 카드의 스위치:

- **설치 / 업데이트 / 다운그레이드 / 다시 설치**는 고른 버전을 카탈로그에서 사용자 폴더(`user://mods/`)로 내려받습니다.
- **끄기 / 켜기**(또는 카드의 스위치)는 모드를 불러올지 정합니다. 꺼진 모드도 파일과 저장 속 데이터는 유지됩니다.
- **삭제**는 확인 후 내려받은 모드를 제거합니다.

이들 작업 뒤에는 **변경 사항은 게임을 다시 시작한 뒤에 적용됩니다** 배너가 뜹니다. Mod Manager 자신은 이 화면에서 삭제하거나 끌 수 없습니다.

**설치됨은 사용 중이 아닙니다.** 게임은 자기 컬렉션이 이름을 적은 모드와 메뉴 셸을 불러옵니다. 설치는 모드를 이용 가능하게 할 뿐입니다. 그 게임의 컬렉션이 모드를 담을 때 비로소 게임에 나타납니다.

## 게임과 컬렉션

**컬렉션** 탭은 먼저 만들어진 게임을 보여 줍니다. 게임이란 *컬렉션*입니다: 이름 붙은 모드 세트와 시작 장소.

![게임 갤러리: Cthangover, My Novel, RPG Plus 카드, 각각 "Ready to play"와 Mods 32/32, 11/11, 36/36, 그리고 Edit scheme 버튼.](assets/games-gallery.jpg)

카드는 게임에 필요한 모든 것이 설치됐는지 알려 줍니다(**플레이 준비 완료**, 또는 **N개 부족** / **설치 (N)** / **켜기 (N)**). 한 버튼으로 빠진 것을 설치하거나 켭니다. **구성 편집**은 게임의 구조를 열고, **＋ 나만의 게임 만들기**는 새 컬렉션을 시작합니다.

### 게임 구성

![My Novel의 구성: Story, Assets, 2D engine 블록과 그 모드들, 각 의존성에서 이를 필요로 하는 모드로 가는 화살표, 그리고 My Novel의 버전 요구 사항을 보여 주는 인스펙터.](assets/collection-scheme.jpg)

구성도는 게임의 *메카닉*(Story, Assets, 2D engine 같은 블록)과 그 안의 모드를 보여 줍니다. 화살표는 의존성에서 그것을 필요로 하는 모드로 향합니다. 카드 위치와 블록은 읽기용일 뿐: 로드 순서를 정하지 않습니다.

블록이나 모드를 고르면 **인스펙터**에 나타납니다. 거기서 게임이 요구하는 버전을 바꿀 수 있습니다: **모든 버전**, **최소 버전**, **정확한 버전**, **버전 분기**(`^1`은 1.x 모두 허용) 등. 이것은 게임의 요구 사항이지 설치된 버전이 아닙니다. **검사**는 문제를 나열하고, **계획**은 컬렉션 적용이 무엇을 설치하고 켤지 보여 줍니다.

![요구 사항 "Exactly 999.0.0"이 설치된 1.0.0과 맞지 않는 모드의 인스펙터: 요구 사항과 설치 버전이 빨간색으로 표시됩니다.](assets/version-mismatch.jpg)

구성도의 다른 버튼들: **+ 메카닉**과 **모드 추가**는 게임을 바꾸고, **복제**는 자기 사본을 만들며(저장 복사도 제안합니다), **JSON**은 원본 정의를 보여 주고, **저장**과 **초기화**는 변경을 남기거나 버리며, **컬렉션 적용**은 계획에 나온 것을 설치하고 켭니다. 바꾼 기본 제공 게임은 **기본 제공 버전으로 되돌리기**로 복원할 수 있습니다. 저장 파일은 남습니다.

게임 변경은 다음 시작 때 적용됩니다. 게임의 저장은 모드가 바뀌어도 쓸 수 있습니다: 게임을 떠난 모드의 데이터는 따로 보관되고 모드와 함께 돌아옵니다.

## 문제가 생겼을 때

1. **모드가 게임에 나타나지 않는다.** 켜져 있는지, 그 게임의 컬렉션이 담고 있는지 확인하세요(**구성 편집**을 여세요).
2. **"설치 실패".** 인터넷 연결을 확인하고 **카탈로그 새로 고침**을 다시 시도하세요.
3. **게임 카드에 부족 또는 문제가 표시된다.** 그 구성과 **검사** 탭을 여세요: 빠진 모드, 버전 차이, 충돌이 나열됩니다.
4. **카탈로그 충돌.** 같은 모드와 버전이 두 카탈로그에 다른 내용으로 공개되었습니다. 신뢰하는 카탈로그를 따르세요.
5. **문서 섹션이 없다.** 그 모드에는 아직 `docs/` 안내서가 없습니다. 대신 manifest 설명이 보입니다.
