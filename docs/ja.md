# Mod Manager — MOD、ゲーム、そのドキュメント

Mod Manager はメインメニューの **MOD とコレクション** 画面です。どの MOD がインストールされているか、それぞれが何をするのかを確認し、オンラインカタログから MOD をインストール・更新し、無効にし、でき上がりのゲームの中身を見て、どの MOD で構成されているかを確かめられます。

常にメニューとともに読み込まれるシェルの一部なので、ゲームを始める前から使えます。

## 開き方

メインメニューで **MOD とコレクション** を選びます。画面には二つのタブがあります:

- **MOD** — ゲームが知っているすべての MOD:インストール済みのものとカタログが提案するもの。
- **コレクション** — でき上がりのゲームと、それぞれを構成する MOD の構成。

**← メニュー** でメインメニューに戻ります。右上の **?** ボタン、または **F1** でコンテキストヒントが有効になります。コントロールにマウスを乗せると働きが分かり、クリックでヒントを固定し、**Esc** で終わります。

## MOD を見て回る

![MOD タブ:左にフィルター、カバー付き MOD カードのグリッド、ヒントが開いた検索ボックス、並べ替えとカタログを更新ボタン。](assets/mods-list.jpg)

各カードには、MOD のカバー、タイトル、作者、出どころのカタログ、使っているゲームの数(**4 個のコレクションに含まれる**)、状態とバージョン、そしてオン/オフのスイッチが並びます。

- **MOD を検索...** はタイトル・作者・識別子で絞り込みます。
- **名前順 / 作者順 / 状態順** がリストを並べ替えます。
- **フィルター** は左側で、**状態**(未インストール、インストール済み、更新あり、古いバージョンあり、ローカルで変更、無効)と**カテゴリー**(ストーリー、ゲームプレイ、ビジュアル、オーディオ、ライブラリ、エンジン、ツールなど)でリストを狭めます。**リセット**でフィルターと検索を解除します。
- **カタログを更新** は公開中 MOD の最新一覧をダウンロードします。

*ローカルで変更* は、インストール済みのファイルがカタログの同じバージョンのコピーと違うことを意味します。たとえば自分で編集中の MOD などです。

## MOD の詳細を見る

カードをクリックするとページが開きます:カバー、バージョン選択、アクション、manifest から来る短い説明、そして MOD が用意していれば**ドキュメント** — この文書のような完全なガイドです。

![ある MOD のページ:Audio Engine のカバーとバージョン、Reinstall と Disable のボタン、"in 4 collections"、説明、そして言語セレクターつきの Documentation セクション。](assets/mod-page.jpg)

ドキュメントは**インストール済み**バージョンのガイドです。バージョン選択で別のバージョンを選ぶと、下のガイドが依然としてインストール済み版のものであることを注意書きが教えてくれます。

**ドキュメントの言語。** 見出し「ドキュメント」の右にあるセレクターは **自動 · UIの言語** で始まります。ガイドはゲームのインターフェース言語に従います。その言語のガイドが MOD にない場合、マネージャーは MOD の既定のガイド、次に英語、そして最初に見つかったものを表示します。ガイドの上の行が実際に表示している言語(たとえば `EN`)を示します。セレクターで言語を自分で選ぶこともできます。ガイドを一つも持たない MOD は、manifest の説明を表示し続けます。

MOD 作者向け:ガイドは `docs/en.md` に(翻訳は `docs/<言語>.md` か `docs/default.md`)、画像はその隣に置きます。たとえば `docs/assets/screen.png` を置いて `assets/screen.png` と参照します。ビューワーは見出し・段落・リスト・引用・コードブロック・リンク・PNG/JPEG/WebP 画像を表示します。HTML、表、アニメーションは実行しません。

## インストール、更新、無効化、削除

MOD ページのボタンとカードのスイッチ:

- **インストール / 更新 / ダウングレード / 再インストール** は選んだバージョンをカタログからユーザーフォルダー(`user://mods/`)へダウンロードします。
- **無効にする / 有効にする**(またはカードのスイッチ)が MOD を読み込むかどうかを決めます。無効の MOD もファイルとセーブ内のデータは残ります。
- **削除** は確認のうえダウンロード済みの MOD を取り除きます。

いずれの操作の後も **変更はゲームの再起動後に反映されます** というバナーが出ます。Mod Manager 自身はこの画面から削除も無効化もできません。

**インストール済みは使用中ではない。** ゲームはコレクションに名前のある MOD とメニューシェルを読み込みます。インストールは MOD を利用可能にするだけです。ゲームに現れるのは、そのゲームのコレクションが MOD を含むときです。

## ゲームとコレクション

**コレクション** タブはまずでき上がりのゲームを示します。ゲームとは *コレクション* のこと:名前のついた MOD のセットと、開始場所です。

![ゲームギャラリー:Cthangover、My Novel、RPG Plus のカード。それぞれ "Ready to play" で Mods 32/32、11/11、36/36、構成を編集ボタンつき。](assets/games-gallery.jpg)

カードは、ゲームに必要なものがすべて揃っているかを教えます(**プレイできます**、または **N 個不足** / **インストール(N)** / **有効化(N)**)。一つのボタンで不足分をインストールまたは有効化します。**構成を編集** はゲームの中身を開き、**＋ 自分のゲームを作る** は新しいコレクションを始めます。

### ゲームの構成

![My Novel の構成:Story、Assets、2D engine のブロックとそれぞれの MOD、各依存関係からそれを必要とする MOD への矢印、そして My Novel のバージョン要件を表示するインスペクター。](assets/collection-scheme.jpg)

構成図はゲームの *メカニクス*(Story、Assets、2D engine などのブロック)とその中の MOD を示します。矢印は依存関係から、それを必要とする MOD へ向かいます。カードの位置とブロックは読むためのもの:ロード順序は決めません。

ブロックか MOD を選ぶと **インスペクター** に表示されます。そこでゲームが要求するバージョンを変えられます:**任意**、**以上**、**固定**、**ブランチ**(`^1` なら 1.x すべて)など。これはゲーム側の要求であり、インストール済みのバージョンではありません。**チェック** は問題を一覧し、**計画** はコレクション適用で何がインストール・有効化されるかを示します。

![要件 "Exactly 999.0.0" がインストール済み 1.0.0 と合わない MOD のインスペクター:要件とインストール済みバージョンが赤で表示されます。](assets/version-mismatch.jpg)

構成図のその他のボタン:**+ メカニクス** と **MOD を追加** がゲームを変え、**複製** が自分のコピーを作り(セーブのコピーも提案します)、**JSON** が生の定義を示し、**保存** と **リセット** が変更を残すか捨て、**コレクションを適用** が計画どおりにインストールと有効化を行います。変更した組み込みのゲームは **組み込み版に戻す** で元に戻せます。セーブは残ります。

ゲームへの変更は次回の起動で反映されます。ゲームのセーブは MOD が変わっても使えます:ゲームから離れた MOD のデータは脇に保管され、MOD とともに戻ります。

## うまく動かないとき

1. **MOD がゲームに現れない。** 有効になっているか、ゲームのコレクションに含まれているか確認してください(**構成を編集**を開く)。
2. **「インストールできませんでした」。** インターネット接続を確認し、**カタログを更新** をもう一度試してください。
3. **カードに「不足」や「問題」と出る。** その構成と **チェック** タブを開いてください:足りない MOD、バージョンのずれ、競合が一覧が出ます。
4. **カタログの競合。** 同じ MOD とバージョンが異なる内容で二つのカタログに公開されています。信頼できるカタログの方を使ってください。
5. **ドキュメントのセクションがない。** その MOD にはまだ `docs/` のガイドがありません。manifest の説明が代わりに表示されます。
